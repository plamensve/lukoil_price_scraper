# Lukoil Price Scraper — GTA Petroleum Edition

Светло Windows десктоп приложение, което **локално** отваря HTML файл,
запазен от [ценовата листа на Лукойл](https://wholesale.lukoil.bg/orders/CeniTermList01072022),
извлича всички таблици по терминали и генерира оформен Excel файл.

**Няма браузърна автоматизация, Chrome разширения, скрити заявки,
автоматично логване или заобикаляне на CAPTCHA.**

## Как се използва

1. Отвори обикновения си Google Chrome и влез в Лукойл с наличния си акаунт.
2. Отвори https://wholesale.lukoil.bg/orders/CeniTermList01072022
3. Избери нужните терминали на сайта (или всички) и натисни **Филтър**.
4. Натисни **Ctrl+S** в Chrome. Избери тип **Webpage, HTML Only**
   (ако има този избор). Запази HTML файла.
5. Стартирай **LukoilPriceScraper.exe**.
6. Натисни **Избери HTML файл** и посочи запазената страница.
7. Прегледай цените, избери кои терминали да бъдат включени
   и натисни **Експорт в Excel (.xlsx)**.
8. Избери папка за Excel файла.

Приложението **не отваря браузър** и не се свързва със сайта на Лукойл.
То обработва само запазения файл от твоя компютър. Страница за вход няма
да даде резултат. Не използвай MHTML — поддържат се само .html и .htm.

## Интерфейс

- Светла корпоративна тема с червени и зелени акценти.
- Лого на **Лукойл** в лявата част на заглавието.
- Лого на **GTA Petroleum** в дясната част.
- Избор на HTML файл, резюме с датата и броя редове.
- Динамично откриване на терминалите от самия HTML файл.
- Табличен преглед на първите 30 избрани записа.
- Excel експорт, активен само при валидни редове и избрани терминали.

## Excel

- Лист **Всички цени** и отделен лист за всеки избран терминал.
- Код, наименование на гориво, мерна единица, нетна цена,
  данъчна основа, ДДС, крайна цена и трите отстъпки.
- Цените са числа, форматирани в евро.
- Филтри, фиксирани колони и заглавни редове.

## Сваляне на готов Windows .exe

1. Отвори [Build Windows EXE](https://github.com/plamensve/lukoil_price_scraper/actions/workflows/build-windows.yml).
2. От последното **успешно** изпълнение отвори **Artifacts**
   и избери **LukoilPriceScraper-Windows**.
3. Разархивирай и стартирай **LukoilPriceScraper.exe**.

Получателят не се нуждае от Python, Chrome разширение или инсталиране
на Python библиотеки. Chrome е нужен само за запазване на нови HTML файлове.
EXE не е цифрово подписан; Windows SmartScreen може да предупреди.

## Локална разработка с PyCharm

Нужен е Python 3.12. В терминала:

    py -3.12 -m venv .venv
    .venv\Scripts\activate
    python -m pip install -r requirements.txt
    python tools/download_logos.py
    python main.py

Логата се изтеглят **по време на build**, а не при всяко стартиране.
При липсващи изображения интерфейсът показва имената като текст.

За собствен EXE стартирай **build_windows.bat**. Резултатът е
**dist/LukoilPriceScraper.exe**.

## Тестове

    python -m unittest discover -s tests -v

Тестовете ползват синтетичен HTML, не отварят сайта на Лукойл.

## Лога и източници

- **GTA Petroleum:** [Официален файл на gtapetroleum.com](https://gtapetroleum.com/wp-content/uploads/2021/03/GTA-logo-1200x800-rgb.jpg)
- **Лукойл:** [Wikimedia Commons корпоративно лого](https://commons.wikimedia.org/wiki/File:Lukoil_company_logo.svg)

Скриптът **tools/download_logos.py** изтегля и преобразува изображенията
в assets/gta.png и assets/lukoil.png, и създава assets/app.ico.
Windows build-ът вгражда изображенията **вътре в EXE файла**.
След компилиране програмата не се нуждае от интернет за тях.

Изображенията съдържат фирмени търговски марки, принадлежащи на
съответните правоносители.

## Структура

|---|---|
| main.py | CustomTkinter интерфейс и локално зареждане на HTML |

| .github/workflows/build-windows.yml | Windows EXE build |

## Забележка

HTML файлът може да съдържа конфиденциална информация — съхранявай го
локално и не го споделяй с неоторизирани лица. Функционалността е
тествана със синтетичен HTML и **предстои проверка с реален файл,
запазен от живия портал на Лукойл**.
