# Lukoil Price Scraper — Windows desktop

Десктоп приложение с **CustomTkinter + Playwright**, което използва
съществуващия ти оторизиран достъп до
[ЛУКОЙЛ — ценови листи](https://wholesale.lukoil.bg/orders/CeniTermList01072022),
прочита ценовите таблици за терминалите и ги експортира в Excel.

## Какво прави

- Отваря **Google Chrome** или **Microsoft Edge**, в който **ти лично** въвеждаш потребителско име, парола и CAPTCHA.
- Използва отделен, постоянен браузърен профил за приложението.
- Проверява дали след вход страницата на Лукойл съдържа ценови редове.
- Извлича **всички девет видими колони**, както и скрития код на продукта.
- Може да експортира само избрани терминали.
- Създава \`.xlsx\` с лист **Всички цени** и отделен лист за всеки терминал.
- Цените се записват като числа, когато са във валиден числов формат.

**Важно:** CAPTCHA не се заобикаля. Ако сесията изтече, трябва да влезеш
отново ръчно. Приложението не съхранява паролата отделно и не качва
данни в облачна услуга. Браузърният профил съдържа чувствителни
сесийни данни и не трябва да се споделя.

## За получателя на готовия EXE

1. Нужни са **Windows 10/11**, интернет и **инсталиран Chrome или Edge**.
2. Изтегли EXE от GitHub Actions (инструкции по-долу).
3. Стартирай \`LukoilPriceScraper.exe\`.
4. Натисни **Отвори Chrome / Edge** и се логни в прозореца на браузъра.
   Въведи CAPTCHA ръчно и избери нужния период.
5. В приложението натисни **Провери входа**.
6. Избери терминалите и натисни **Извлечи цени и запази .xlsx**.
7. Избери папка и име на Excel файла.

EXE е самостоятелен — **получателят няма нужда от Python**.
Инсталираният Chrome или Edge обаче е задължителен.

### Къде се пази сесията?

\`%LOCALAPPDATA%\LukoilPriceScraper\BrowserProfile\`

Това е **отделен браузърен профил**, не личният ти Chrome профил.
След изход от приложението браузърът се затваря, но сайтът може да е
запазил сесията. Ако Лукойл изисква повторен вход, отново се попълва CAPTCHA.

## Генериране на EXE — GitHub Actions (препоръчително)

1. Отвори **Actions → Build Windows EXE** в това GitHub репо.
2. Натисни **Run workflow** или отвори последното успешно изпълнение
   след push в \`main\`.
3. След **успешно** изпълнение отвори секцията **Artifacts**.
4. Изтегли **LukoilPriceScraper-Windows**, разархивирай ZIP файла.
5. Изпрати \`LukoilPriceScraper.exe\` на потребителя.

Линк: https://github.com/plamensve/lukoil_price_scraper/actions/workflows/build-windows.yml

**Бележка:** Файлът не е цифрово подписан. Windows SmartScreen или
антивирусната програма могат да покажат предупреждение. За широко
разпространение е желателно подписване на приложението с доверен сертификат;
не препоръчваме изключване на системните защити.

## Генериране на EXE локално

Нужен е **Python 3.12** на твоя Windows компютър.
Стартирай \`build_windows.bat\` от папката на репото.

Резултатът ще е:

\`dist\LukoilPriceScraper.exe\`

За разработка:

\`\`\`powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
\`\`\`

За тестовете:

\`\`\`powershell
python -m unittest discover -s tests -v
\`\`\`

## Структура

| Файл | Предназначение |
|---|---|
| \`main.py\` | CustomTkinter интерфейс |
| \`lukoil_scraper/browser.py\` | Chrome/Edge сесия и работен поток |
| \`lukoil_scraper/parser.py\` | Парсване на повторени \`thead\` / \`tbody\` |
| \`lukoil_scraper/excel_export.py\` | Excel workbook + форматиране |
| \`tests/test_parser.py\` | Тестове със синтетичен HTML |
| \`.github/workflows/build-windows.yml\` | Компилиране в GitHub Actions |

## Ограничения

Структурата е изградена спрямо HTML фрагментите, предоставени за страницата
\`/orders/CeniTermList01072022\`. Тестовете използват синтетични HTML
данни. **Не е извършван live тест в защитения портал**, защото няма достъп
до потребителската сесия. Възможно е Лукойл да промени HTML структурата
или политиката си за сесии; тогава парсърът може да се нуждае от корекция.

Използвай приложението само с акаунт и данни, за които имаш право на достъп.
