# Lukoil Price Scraper — Windows desktop

Локално **CustomTkinter** приложение за извличане на ценовите таблици от
https://wholesale.lukoil.bg/orders/CeniTermList01072022 и създаване на Excel.

**Няма Chrome разширение и няма автоматично попълване на вход или CAPTCHA.**
Приложението чете HTML от страницата, която вече е отворена в Chrome,
без да я презарежда при извличането.

## Начин 1: Автоматично извличане от отворения таб (препоръчителен)

> **Важно:** обикновен Chrome, стартиран без debugging, не позволява на
> друго десктоп приложение да чете отворените му табове. Затова приложението
> стартира специален Chrome профил с debugging интерфейс само на
> **127.0.0.1:9333**, използвайки Chrome DevTools Protocol (CDP).
> Не може автоматично да използва сесията от обикновен Chrome.

1. Стартирай \`LukoilPriceScraper.exe\`.
2. Натисни **Отвори Chrome за цените**.
3. Chrome ще отвори страницата на Лукойл. **При първото използване**
   влез с акаунта си и CAPTCHA ръчно, както обикновено. В бъдеще Chrome
   може да запази сесията (докато тя е валидна).
4. Остани на страницата с ценовите таблици. Ако е нужно, избери
   терминали и натисни „Филтър“ на сайта.
5. Върни се в десктоп приложението и натисни **Прочети отворения таб**.
6. Маркирай терминалите и натисни **Извлечи отворената таблица → Excel**.
7. Избери къде да бъде записан \`.xlsx\` файлът.

Ако сесията е изтекла, Chrome сам ще покаже страницата за вход; приложението
няма да опитва да попълни CAPTCHA. Скрейпингът **не навигира**, не
презарежда и не логва потребителя — чете вече показания HTML от отворения
Lukoil таб.

### Профил и сигурност

Chrome използва отделен профил:

\`%LOCALAPPDATA%\LukoilPriceScraper\ChromeProfile\`

CDP портът е само на **127.0.0.1**, не е изложен в мрежата.
Въпреки това **други локални програми** с достъп до този порт могат да
контролират Chrome и сесията в този специален профил. Затваряй този
Chrome прозорец, когато приключиш. Не използвай този профил за други
сайтове или чувствителни акаунти. Никога не отваряй/препращай порт 9333
към публична или локална мрежа.

Ако Chrome остане отворен, приложението може да се свърже отново към него
при следващо стартиране. За целта портът не трябва да е зает от друга
услуга или Chrome debugging инстанция.

## Начин 2: Вече си логнат в обикновен Chrome (без debugging)

Ако **не искаш специален Chrome профил или нов вход**, използвай
резервния вариант с HTML файл:

1. Отвори ценовата листа в твоя обикновен Chrome (вече логнат).
2. Избери **Ctrl+S**, запази страницата като **Webpage, HTML Only**
   (ако Chrome предлага тази опция).
3. В десктоп приложението натисни
   **Алтернатива: Импортирай запазена HTML страница**.
4. Избери HTML файла и натисни **Извлечи отворената таблица → Excel**.

Импортът чете HTML локално и няма нужда от Chrome debugging. Изтрий
запазения HTML файл след използване, ако съдържа поверителна информация.

## Excel формат

- Лист **Всички цени**.
- Отделен лист за всеки избран терминал.
- Код на продукта, вид гориво, мерна единица, нетна цена, данъчна основа,
  ДДС, цена с ДДС и трите отстъпки.
- Числовите стойности са реални Excel числа.

## Изтегляне на Windows EXE

1. Отвори:
   https://github.com/plamensve/lukoil_price_scraper/actions/workflows/build-windows.yml
2. Избери последния **успешен** Build Windows EXE.
3. От секция **Artifacts** изтегли **LukoilPriceScraper-Windows**.
4. Разархивирай и стартирай \`LukoilPriceScraper.exe\`.

Получателят няма нужда от Python, но за CDP режима трябва да има
инсталиран **Chrome или Microsoft Edge**. EXE не е цифрово подписан;
възможно е Windows SmartScreen да покаже предупреждение.

## Стартиране през PyCharm

\`\`\`powershell
pip install -r requirements.txt
python main.py
\`\`\`

## Създаване на EXE на Windows

Инсталирай Python 3.12 и стартирай \`build_windows.bat\`. Резултатът
ще бъде \`dist\LukoilPriceScraper.exe\`.

## Автоматични тестове

\`\`\`powershell
python -m unittest discover -s tests -v
\`\`\`

Тестовете използват синтетичен HTML и mock Chrome. Не се логват в
сайта, не заобикалят CAPTCHA и не извличат данни от реални акаунти.
Реалната HTML структура може да се промени, затова следва да се
валидира с оторизирана сесия.

## Архитектура

- \`main.py\` — CustomTkinter GUI.
- \`lukoil_scraper/browser.py\` — Playwright CDP, намиране на отворения таб,
  извличане без навигация.
- \`lukoil_scraper/parser.py\` — ценовите таблици (\`thead\`/\`tbody\` по терминали).
- \`lukoil_scraper/excel_export.py\` — Excel с форматиране.
- \`tests/\` — regression тестове за HTML и Chrome tabs.
- \`.github/workflows/build-windows.yml\` — Windows build.

Използвай приложението само с данни и акаунт, за които имаш право на достъп.
